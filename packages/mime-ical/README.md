# @metreeca/mime-ical

[![npm](https://img.shields.io/npm/v/@metreeca/mime-ical)](https://www.npmjs.com/package/@metreeca/mime-ical)

iCalendar processing tasks for [@metreeca/mime](https://github.com/metreeca/mime).

# Installation

```shell
npm install @metreeca/gear       # the job executor
npm install @metreeca/mime-ical  # this package
```

> [!IMPORTANT]
>
> Node.js 22 or later is required.

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.
